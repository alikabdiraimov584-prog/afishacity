# Готовые карты городов FREE

`osm_dubai.db.gz` — проверенный снимок мест Дубая (OSM + Overture Maps), собран
офлайн скриптами `scripts/dubai_offline/` основной ветки. `osm_dubai.meta.json`
хранит sha256 архива; `deploy/install.sh` скачивает карту, сверяет сумму и
ставит её в `/opt/afishacity/data/osm_dubai.db`.
